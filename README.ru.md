# ESO Addons for Mac — Minion Alternative for macOS

[English](README.md) · [Русский](README.ru.md) · [Français](README.fr.md) · [Español](README.es.md)

[![Build and tests](https://github.com/TheMoldex/minion-alternative-eso-macos/actions/workflows/build.yml/badge.svg)](https://github.com/TheMoldex/minion-alternative-eso-macos/actions/workflows/build.yml)

Менеджер аддонов **The Elder Scrolls Online** для macOS на Apple Silicon. Самостоятельная альтернатива Minion: каталог ESOUI, автообновление аддонов, установка обязательных библиотек и ручные копии настроек. Интерфейс на русском, английском, французском и испанском языках.

## Установка

1. Скачай **`ESO-Addons-for-Mac.zip`** из [последнего релиза](https://github.com/TheMoldex/minion-alternative-eso-macos/releases/latest) и распакуй. Автоматический архив GitHub «Source code» содержит исходники для сборки, а не готовое приложение.
2. Перенеси `ESO Addons for Mac.app` в **«Программы»** и открой. Если macOS запросит доступ к **«Документам»**, разреши его: там лежат аддоны ESO.
3. Приложение найдёт стандартную папку `~/Documents/Elder Scrolls Online/live/AddOns`. Если она другая, открой шестерёнку внизу → **«Основные → Выбрать папку»** и укажи `live` или `AddOns`. Для тестового сервера выбери `pts`.
4. Проверь список «Установлено». Новые аддоны ставятся через «Найти аддоны», доступные обновления — через «Обновления → Обновить всё». После изменений выполни `/reloadui` в игре.

Нужны **macOS 14 или новее и Mac с Apple Silicon**. Сборка подписана локально, без сертификата Developer ID и проверки Apple (notarization). Если macOS предлагает **«Всё равно открыть»**, кнопка находится в «Системные настройки → Конфиденциальность и безопасность». Отключать Gatekeeper целиком не нужно.

В списке явно показано, есть ли обновление, актуальна ли версия или локальная версия новее. Если проверить версию нельзя, это написано отдельно. Рядом показаны версии, а метки «Аддон / Библиотека» сохраняются. Названия категорий и их значки загружаются из ESOUI и сохраняются в кэше. Это значки категорий, как в Minion. Скриншоты самого аддона показаны отдельно в верхней части его карточки.

## Переход с Minion на macOS

Выбери ту же папку AddOns, которую использовал Minion. Приложение обнаружит существующие аддоны и прочитает подходящие записи Minion для определения источников ESOUI. Переустанавливать всё или переносить SavedVariables не требуется. Настройки Minion не меняются. Перед установкой и обновлением здесь закрой Minion. Это самостоятельное приложение, а не официальный выпуск или ответвление Minion.

## Как пользоваться

Тяни вертикальные границы мышью, чтобы менять ширину бокового меню и карточки аддона. Размеры сохраняются после перезапуска. Выбранную границу также можно двигать стрелками влево и вправо. В узком окне кнопки и фильтры переходят на несколько строк. Шестерёнка внизу бокового меню открывает настройки; также работает Command–запятая. Во вкладке «Основные» находятся папки ESO, язык и параметры копий. Во вкладке «Обновления» — автообновление, параллельные загрузки, исключения и версия приложения.

Правый клик по строке аддона открывает меню: описание, установка/обновление/переустановка, страница ESOUI, папка установленного аддона и удаление. Действия относятся к строке, по которой нажали, даже если выбран другой аддон. Удаление использует то же подтверждение и проверку зависимостей, что и кнопка в карточке.

- **«Установлено»** показывает существующие аддоны. Записи Minion для выбранной папки читаются без изменения его настроек.
- **«Найти аддоны»** ищет по названию, автору и папкам. Выбери аддон, нажми **«Установить»**, проверь список аддонов и библиотек, затем подтверди.
- **«Обновления»** показывает распознанные аддоны с устаревшими версиями. **«Обновить всё»** сначала открывает список изменений. Более новые локальные версии автоматически не заменяются старыми.
- **«Резервные копии → Настройки и перенос»** создаёт ручные копии настроек и аддонов. **«Откат обновлений»** хранит копии папок перед установкой и обновлением.
- **«Удалить аддон»** сначала показывает папки для удаления и библиотеки с перечнем других аддонов, которые их используют. По умолчанию библиотеки сохраняются. Галочка **«Удалить неиспользуемые библиотеки»** добавляет только зависимости, нужные этому аддону и этому набору библиотек. Общие библиотеки остаются. Библиотеку нельзя удалить, пока она нужна другому сохраняемому аддону. Выбранные папки перемещаются в Корзину macOS без создания копии в приложении. Для возврата выбери **«Вернуть обратно»** в Корзине. SavedVariables остаются на месте. При ошибке уже перемещённые папки возвращаются на место; если это не удалось, сообщение покажет их расположение в Корзине.
- В карточке есть **«Описание» / «Что нового»** из API ESOUI. Текст сохраняется на час, показывается без выполнения HTML и без загрузки внешних картинок. Язык автора сохраняется.
- После установки или обновления выполни **`/reloadui`** в игре.
- **Русский / English / Français / Español** переключается в «Настройки → Основные» и сохраняется между запусками. Описания аддонов остаются на языке автора.
- Метки **«Аддон» / «Библиотека»** видны в списках, карточках и перед установкой. Тип берётся из данных ESOUI или локального манифеста, а не из начала названия. Автоматически добавленные зависимости отдельно подписаны в списке установки.

Под поиском можно сочетать фильтры по **категории**, типу **«Аддон / Библиотека»** и **версии ESO**. Совместимость берётся из списка, указанного автором в ESOUI; при выборе конкретной версии записи без этих данных не показываются. Сортировка — **по имени**, **загрузкам** или **дате обновления**, стрелка меняет направление. **«Сбросить фильтры»** также очищает поиск и возвращает исходный порядок: по имени для установленных аддонов, по загрузкам для каталога. Рядом показано число результатов. Фильтры каталога и разделов «Установлено / Обновления» сохраняются отдельно, пока приложение открыто. Они меняют отображаемый список; **«Обновить всё»** по-прежнему показывает все распознанные обновления перед подтверждением.

Каталог сохраняется на час; ручная проверка обращается к серверу не чаще раза в минуту. Ручная установка сначала показывает список изменений. Не запускай ручное обновление одновременно через Minion и это приложение.

## Фоновое обновление

**«Автообновление»** включено по умолчанию и отключается в «Настройки → Обновления» или меню приложения в строке меню macOS. Первая проверка — через час после включения; время следующей видно в настройках обновлений. Обновляются только распознанные установленные аддоны, не исключённые из обновления, вместе с обязательными зависимостями. Перед заменой создаются копии. Посторонние аддоны из каталога автоматически не ставятся.

Проверка откладывается, пока запущены ESO или Minion, выполняется другая операция, открыто подтверждение или заблокировано восстановление. Список процессов повторно проверяется перед заменой файлов. После паузы следующая попытка будет через пять минут, после других ошибок — через пятнадцать. Состояние и полная ошибка видны в «Настройки → Обновления» и меню приложения. Компактный индикатор ошибки слева открывает настройки обновлений. Пока настройки открыты, фоновое обновление аддонов приостановлено.

При включённом автообновлении закрытие окна оставляет приложение работающим в строке меню. **«Открыть окно»** возвращает окно, **«Завершить ESO Addons»** останавливает приложение. Во сне Mac проверки не выполняются; просроченные возобновляются после пробуждения. Системной службы и автоматического запуска при входе нет. После перезагрузки Mac приложение нужно открыть снова.

## Исключения, несколько папок и журнал

В карточке аддона или по правой кнопке выбери **«Не обновлять автоматически»**. Все исключения выбранной папки собраны в «Настройки → Обновления → Исключения из автообновления». Аддон исключается и из **«Обновить всё»**, и из фонового обновления для этой папки ESO. Обновить его отдельной кнопкой можно. **«Снова обновлять»** отменяет исключение. Если другому аддону нужна новая версия исключённой библиотеки, установка остановится и попросит разрешить её обновление.

В «Настройки → Основные» можно переключаться между сохранёнными папками ESO, например `live` и `pts`. **«Выбрать папку»** добавляет папку в список, **«Убрать из списка папок»** забывает её без удаления файлов. Источники, исключения, копии для отката и журнал хранятся отдельно для каждой папки. Фоновое обновление работает с выбранной папкой.

Настройка **«Параллельных загрузок»** в «Настройки → Обновления» позволяет выбрать от 1 до 4, по умолчанию 3. Все архивы скачиваются и проверяются до замены аддонов. При ошибке скачивания или проверки архив пропускается. Остальные аддоны обновляются, если им хватает уже установленных или успешно скачанных библиотек. Пропущенные аддоны и причины видны в результате операции.

**«Журнал операций»** сохраняет последние 500 записей выбранной папки: названия аддонов, время, результат и этап ошибки. Есть фильтр ошибок и копирование журнала. Счётчики скачиваний и избранного берутся из ESOUI и показаны в списках и карточках; в карточке также есть скачивания за месяц.

## Ручные копии, перенос и сброс настроек

1. Закрой ESO и Minion.
2. Открой **«Настройки → Основные → Резервные копии»** и выбери папку для копий. Подойдёт другой диск или локальная папка облачного хранилища.
3. Перейди в **«Резервные копии → Настройки и перенос»**. Для полного переноса оставь **«Включить файлы аддонов»**. Без этой галочки сохраняются только настройки и перечень аддонов; сам перечень ничего не устанавливает.
4. Нажми **«Создать ручную копию»**. Эти копии хранятся, пока ты сам не удалишь их в приложении или Finder. Лимит копий для отката на них не действует.
5. Для переноса скопируй целиком папку `ESO-Backup-…` на другой компьютер. Выбери там папку ESO, нажми **«Открыть копию с другого компьютера»**, выбери копию и проверь список перед восстановлением.

Перед созданием ручной копии можно задать имя. Позже выбери копию и нажми **«Переименовать»** или используй меню по правой кнопке. Если имя пустое, показывается дата. Имя хранится внутри копии и сохраняется при переносе.

В обоих списках копий можно выбрать несколько строк с Command или Shift. **«Удалить выбранные»**, клавиша Delete или **ПКМ → «Удалить копии»** открывают подтверждение и переносят целые папки копий в Корзину macOS. Для возврата используй **«Вернуть обратно»** в Корзине. Удаление копий не затрагивает установленные аддоны и настройки игры. Копии незавершённого восстановления защищены.

В копию входят `SavedVariables/*.lua` и их `.lua.bak`, `UserSettings.txt`, `AddOnSettings.txt`, список аддонов, сведения об источниках и исключениях, а с галочкой — ещё и файлы аддонов. Перед восстановлением проверяются суммы SHA-256. Заменяются только перечисленные файлы и папки; остальные сохраняются. При ошибке или прерывании восстановление откатывается через локальный журнал. Имена учётных записей и персонажей внутри настроек при переносе не переписываются.

**«Сбросить настройки аддона»** — отдельная команда в карточке и меню по правой кнопке. Она показывает файлы SavedVariables, связанные с манифестами аддона, и переносит только их в Корзину. Общие настройки защищены, отдельные библиотеки остаются. Копия аддона при сбросе не создаётся. ESO нужно закрыть, иначе игра может записать старые настройки обратно при выходе. [Объяснение SavedVariables на ESOUI](https://www.esoui.com/forums/showthread.php?t=9235).

## Источники и библиотеки

Несколько проектов ESOUI могут использовать одну папку. Сначала учитывается твой выбор источника или запись Minion для этой папки. Затем приложение ищет однозначное совпадение в каталоге. При спорном совпадении выбери аддон во вкладке «Установлено» и нажми **«Выбрать источник ESOUI»**. Массовое обновление не затрагивает папки без определённого источника.

Обязательные библиотеки и их минимальные версии берутся из каталога. Необязательные библиотеки автоматически не ставятся. Если нужную библиотеку нельзя безопасно подобрать, установка останавливается и показывает её название. После распаковки зависимости повторно проверяются по манифестам.

Поддерживаются ZIP-архивы со списком папок в каталоге ESOUI. Заброшенные проекты исключены из поиска. Неподдерживаемый или небезопасный архив останавливает установку. Лишние папки только с небольшими текстовыми документами пропускаются; исполняемые файлы и действующие манифесты вне каталога по-прежнему блокируются. Так обрабатываются заглушки старой папки Ravalox Quest Tracker.

## Сохранность файлов

Начиная с 0.5.5 автоматические копии для отката содержат контрольные суммы SHA-256. Перед откатом и аварийным восстановлением проверяются все записанные файлы. Старые автоматические копии без контрольных сумм сохраняются: их можно посмотреть или удалить, но кнопка восстановления отключена, поскольку полноту такой копии проверить невозможно. Ручные переносимые копии уже содержат контрольные суммы и остаются совместимыми.

Недоступный файл аддона или повреждённые данные восстановления не скрывают список установленных аддонов. Изменение файлов приостанавливается, а сообщение указывает проблемный путь. После исправления прав или данных восстановления повтори проверку. Флажок Finder «Защита» проверяется до замены файлов. Откат библиотеки и переносимая копия не могут нарушить ранее работавшие зависимости остальных аддонов. Незавершённое восстановление ждёт закрытия ESO и Minion.

- При установке и обновлении заменяются только затронутые папки внутри **AddOns**.
- Установка, обновление и удаление аддона сохраняют **SavedVariables** и настройки игры. Эти файлы меняются только по отдельной команде сброса настроек или восстановления ручной копии. Настройки Minion не меняются.
- При обновлении Tamriel Trade Centre сохраняются существующие `PriceTable*.lua` и `ItemLookUpTable*.lua`. Цены и объявления по-прежнему синхронизирует наш отдельный клиент TTC.
- Загрузки идут по HTTPS с проверкой адресов и контрольной суммы MD5 из ESOUI. MD5 проверяет целостность, а не подпись автора.
- Проверяются пути в ZIP, повторяющиеся имена, ссылки, размеры распаковки и CRC. Данные распаковываются с ограничением размера во временную папку до замены аддонов.
- Копии затронутых папок и сведения об источниках находятся в `~/Library/Application Support/ESOAddonsMac/`. Прерванная установка или восстановление возвращается к прежнему состоянию при следующем запуске с той же выбранной папкой.
- В «Настройки → Основные → Резервные копии» есть **«Хранить все» / «Последние 5 / 10 / 20»**. По умолчанию хранятся все. Выбранный лимит удаляет старые завершённые копии после успешной установки, обновления или восстановления в выбранной папке. Копии для незавершённого восстановления сохраняются. Удалённые аддоны возвращаются из Корзины macOS. Настройки игры и SavedVariables в эти копии не входят.
- У папок аддонов «только чтение», принадлежащих твоей учётной записи, перед заменой или очисткой временных копий добавляется запись для владельца. Права других пользователей сохраняются, содержимое резервной копии не меняется. При ошибке восстановления список установленных аддонов и сохранённый каталог всё равно доступны для просмотра; действия с файлами остаются заблокированными до успешного восстановления.
- Параметры приложения хранятся в домене `local.denstash.ESOAddonsMac`. В AddOns создаётся скрытый `.eso-addons.lock`, который защищает от одновременной работы двух экземпляров приложения.

## Скриншоты аддонов

Миниатюры появляются в верхней части карточки выбранного аддона. Нажми миниатюру, чтобы открыть большой просмотр: есть кнопки назад/далее, стрелки на клавиатуре и переключение «Увеличить / Вписать». В увеличенном виде изображение можно прокручивать. Оригинал загружается только при открытии. Если автор не добавил скриншоты, это показано явно; при ошибке загрузки в просмотре есть кнопка «Повторить».

Загружаются только изображения из отдельного списка ESOUI и только с проверенных HTTPS-адресов его CDN. Произвольные картинки из текста описания не открываются. При смене аддона запросы его представления отменяются. Изображения сохраняются локально на семь дней: не более 64 файлов и 96 МБ. Описание и список скриншотов получают одним запросом для выбранного аддона.

## Сборка и проверка

Нужны Xcode Command Line Tools. Java и сторонние пакеты Swift не требуются.

По умолчанию сборка подписывается локально. При замене сборки подпись меняется, и macOS может снова запросить доступ к «Документам». Обычный перезапуск той же сборки её подпись не меняет. Если есть сертификат подписи кода, его можно передать при сборке через `ESO_SIGNING_IDENTITY`. Скрипт не создаёт и не импортирует сертификаты.

```sh
./build.sh /tmp/ESOAddons.app
```

При сборке запускаются локальные проверки. Для проверки настоящего скачивания из ESOUI, установки, резервной копии, отката и восстановления прерванной установки **во временной папке**:

```sh
ESO_LIVE_TESTS=1 ./build.sh /tmp/ESOAddons.app
```

Сборка и проверка выполнены локально на Mac с Apple Silicon. Первый запуск на другом Mac, Intel и все архивы каталога ESOUI не проверялись. Описание сборки и проверок GitHub Actions находится в `.github/workflows/build.yml`.

Это независимое неофициальное приложение. Оно не связано с ESOUI, MMOUI, Minion, ZeniMax или Bethesda. Аддоны принадлежат их авторам и скачиваются из ESOUI по запросу пользователя.

## Обновления приложения

При каждом запуске выполняется свежий запрос к GitHub. Затем проверка повторяется раз в час, пока приложение работает. **«Проверить версию приложения»** в «Настройки → Обновления» запускает новую проверку вручную; кнопка также есть в меню приложения и меню в строке macOS. Новая версия предлагается, только когда к релизу прикреплён готовый ZIP приложения. Черновики и предварительные выпуски пропускаются, версии сравниваются по числам, более старая версия не предлагается.

Окно показывает новую версию и список изменений. **«Позже»** закрывает его; заметная плашка «Доступна версия…» остаётся слева. Проверка раз в час не открывает повторное уведомление для той же версии, но сообщит о следующем выпуске. **«Скачать обновление»** открывает проверенную страницу релиза GitHub. Скачай ZIP, закрой приложение и замени его в «Программах». Установка выполняется вручную. Ошибка сети не мешает обычной работе; при ручной проверке показывается результат. GitHub запрашивается без входа в аккаунт; файлы ESO и учётные данные туда не отправляются.

Для перехода на первый публичный выпуск установи 0.5.6 вручную один раз. Локальные версии до 0.5.5 включительно используют прежний адрес репозитория и не увидят этот релиз. Старые сборки без проверки обновлений тоже требуют одного ручного обновления. Менеджер использует `TheMoldex/minion-alternative-eso-macos`; до появления стабильного релиза с нужным ZIP показывается отсутствие готовой сборки.

Для новой публичной версии обнови оба номера в `build.sh`, собери и проверь приложение, затем создай стабильный релиз GitHub `vX.Y.Z`, совпадающий с версией приложения. Перед публикацией прикрепи `ESO-Addons-for-Mac.zip` и контрольную сумму SHA256. Текст релиза появится в окне обновления.

## Если что-то не работает

Проверь выбранную папку ESO и сбрось фильтры, если аддон не виден. «Версию не удалось проверить» означает, что приложение не может подтвердить актуальность. При ошибке доступа или восстановления список остаётся доступен для просмотра, а сообщение указывает проблемный путь. Исправь указанную причину и повтори проверку. Подробности доступны в «Журнал операций → Только ошибки».

Создай [обращение на GitHub](https://github.com/TheMoldex/minion-alternative-eso-macos/issues): укажи версию приложения, macOS, модель чипа, шаги и текст ошибки. Перед отправкой убери из журналов имена учётных записей, личные пути и содержимое SavedVariables.
